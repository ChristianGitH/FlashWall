/*\ IMAGES COPIES LOGIC /*\
Si modération OFF :
Images ajoutées avec leurs copies, status = 1 OK

Si modération ON :
Images ajoutées seules puis copies ajoutées lorsque image validées status = 1 OK

Si modération passe de ON vers OFF :
Ajout de copies pour toutes les images non-approuvées.

Si modération passe de OFF vers ON :
Suppression des copies pour toutes les images non-approuvées

Si image change pour status = 1
Ajout de copies

Si image change pour status !=1
Suppression des copies

Si ajout d'image avec Moderation ON :
Pas de copies créées

Si ajout d'image avec modération OFF
Copies crées lors de l'ajout. status = 1 OK

Si nombre d'images supérieur à X images, on garde les images affichées en mémoire.
Si pas de nouvelles images, on remet les images gardées en mémoire dans le diaporama.
